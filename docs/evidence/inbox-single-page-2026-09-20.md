# 待办单页验收

## 范围

待办采用单页入口，标题固定为「待办」，顶部提供「待处理 / 我发起 / 已结束」快捷视图。一级导航进入默认选择待处理。待办及其审核详情不展示二级侧栏；知识库、接入和设置保留各自导航。

搜索、类型筛选和列表滚动位置按工作区、身份、授权版本及视图隔离保存于当前页面会话。详情返回恢复原视图；批量审核保留独立处理页面和返回入口。视图切换保留键盘焦点，旧 scope 链接继续可用。

本轮不修改事项状态、读取范围、权限、责任归属、排序或后端接口。已结束包含已发布、无变化、已替代、已解决和已忽略，不代表全部成功完成。

## 实现边界

- `web/src/UnifiedInbox.tsx`：固定标题、快捷视图、筛选与滚动快照、键盘焦点。
- `web/src/ProductApp.tsx`：侧栏呈现、视图状态和详情返回路由。
- `web/src/ProductApp.test.tsx`：导航、详情返回、筛选恢复、滚动恢复和批量审核回归。
- `web/src/styles.css`：三个等宽分段按钮和可见焦点样式。

以上文件包含工作区已有改动，本记录仅描述待办单页增量。

## 限制

筛选快照不跨整页刷新持久化，刷新通过 URL 恢复快捷视图。责任归属、优先级排序及新增状态/时间筛选不在本轮范围。未执行审核、发布等真实写入操作，相关操作依赖现有自动化测试覆盖。
