# T006 桌面设计约束

产品型工作区，Standard 强度。目标用户是来源维护者、语义建模者和独立审核发布者。复用当前中性画布与紧凑控件，不创建任务中心或营销页。

- 主结构：来源候选打开完整建模工作面；左侧为对象列表，右侧为当前对象定义/关系与依据；顶部固定可扫读版本状态，阶段页签连接建模、验证与发布。变更与发布保留旧资产版本入口，增加服务端语义生产恢复入口。
- 识别特征：局部语义对象与固定物理字段用可读名称呈现，关系引用可追踪到目标，不要求录入 UUID。对象列表、来源成员列表和验证结果构成实际数据可视资产，不添加无关照片。
- 颜色与字体：继承现有系统字体和 CSS tokens；新增表面白色 #ffffff、画布 #f7f8fa、文字 #20242b、次要文字 #626975、边界 #dde1e6，选择强调 #2859b8、成功 #22704c、警告 #93621d、错误 #b53c39。正文 13px/1.6，字段 12px，标题 18px/1.4，字距 0。
- 间距和尺寸：4/8/12/16/24px；对象卡圆角 6px，包含区无边框，禁止嵌套卡。1440x900 双列；1024x768 仍为桌面工作区，可折叠对象导航，主内容至少 420px，文本和动作允许换行但不相互覆盖。
- 交互：阶段页签、对象选中、保存后精确版本反馈和错误后恢复入口；工具用 lucide 图标及 aria-label/title，焦点 2px 实线；不加无意义进场动画，遵循 reduced motion。
- 状态：加载、空、禁止、失效、未知结果、未保存、版本冲突、规则未决、验证失败、已发布与回滚均明确。真实后台失败不使用演示内容。AI 模式及未知费用直接显示实际字段；业务声明不预勾选、不由模型批准。
- 验收：两个指定桌面尺寸实际截图、键盘 Tab/焦点、网络断连后服务端恢复、清除 localStorage 和刷新；不增加移动测试范围。
