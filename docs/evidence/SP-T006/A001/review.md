## 风险复核

- 回滚事件动作按回滚父记录生成；保持投影严格校验，真实 outbox 和 Git writer 重放覆盖中间回滚及二次回滚。
- 目录兼容仅增加合法 `pfd_` 读取分支；仍经 `ParsePhysicalFieldID` 验证类型及格式，历史 UUID 路径不变。全量目录集成、生产组合和 race 回归通过。
- 写入未知结果只允许显式重试同一幂等键，不自动重复生成。读取错误不切回 fixture；身份和请求 epoch 隔离旧结果。
- 后端新版本不覆盖未保存纠正；版本冲突需显式放弃本地内容。保存、验证、审核、发布按钮互锁，不使用旧验证批准新内容。
- 回滚返回的发布 ID 固定在 URL，重新打开和刷新保留该发布；拒绝不同生产根的 release 定位。
- 来源返回及生产列表返回的路由已核对。候选忽略保留显式依据，已存在生产记录或旧恢复记录时不开放忽略。
- 不修改默认 Compose、迁移、SDK、费用授权边界或共享基础设施。所有隔离资源清理经 owner 校验。
