## Implemented Boundaries

- Real PublishProposal composes only previously published pins plus the governed target. Per-binding-version execution pins inherit original physical projections. Legacy bindings cannot borrow new bindings' physical provenance. Conflicting projections for one dataset refuse publication atomically. Rollback rechecks latest sequence after acquiring the workspace lock and preserves unrelated drafts.
- Plan digests preserve high-precision JSON numbers and cover complete immutable physical IR. Formal JoinContract refs define all typed equality pairs; content cannot override them. Free expressions, unsupported transforms/cardinality, missing own binding pins and unknown types fail closed. Public plans omit private source/physical IR; the digest is server-owned and opaque.
- Persisted plan ID/digest drives bounded PostgreSQL execution after current principal, credential, consumer, binding, workspace, asset and source checks. No public SQL input. Atomic claims precede external SELECT; same-key replay is metadata-only and never re-executes. Lost-process claims become unknown, not runnable again.
- Dedicated source credentials require actual read-only grants, including table/column DML and reachable NOINHERIT roles. DSNs match frozen authority, reject fallbacks/downgrades and force extended protocol. Plaintext requires explicit development/test configuration. Source logging policy is fail-closed. Read-only transactions, one absolute deadline, row/byte limits and durable cancellation bound execution.
- Current runtime policy intersects deployment limits; effective limits/version are recorded. Cancel authorizes current owner and grants without requiring an old running plan to remain fresh enough for new execution. Cancellation responses and completed runs use authoritative persisted metadata.
- REST canonical execute/get/cancel, MCP, CLI, TypeScript SDK, actual Ask and Operations share the service. New credentials opt in to semantic.execute; old credentials do not inherit it. Result rows remain ephemeral. Public source IDs use TypeIDs; exact numeric cells and UUID cells serialize as strings.
- Migration 21 records plans/runs/pins and statuses. Empty-state down restores schema 20 contracts; populated history/pins refuse down. Production Docker defaults to no UAT; local Compose opts in. Tar release performs its own explicit production embed, ignores external Go workspace/settings, fingerprints source/embedded bytes and SECURITY, records migration 21 and unreviewed local-candidate identity, checks Go binary buildinfo plus production pnpm transitive SBOM name/version sets, and compares archived inputs against verified staging inputs.
