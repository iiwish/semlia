Preflight CUA inspection confirms the current local preview has an explicit local-UAT
identity indicator, a real workspace selector and server-connected catalog. Its member
view's demonstration disclosure is visible. The production App path requires an
authenticated SessionRuntime and renders MemberAdministrationView instead. Therefore
the development preview cannot be presented as an authenticated all-menu hosted journey.

The local Dockerfile preflight enables UAT at image-build time by default. T007's required
production-build gate separates default production assets from explicit local-preview
UAT assets. Prior vulnerability scans prove their scanner results, not this missing
production-identity boundary or hosted deployment readiness.
