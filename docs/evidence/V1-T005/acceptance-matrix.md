## 证据边界

最终门禁与产物以本目录的实际回执汇总为准。Linux Docker smoke/security 镜像与 darwin 本地 RC 是不同二进制，只能关联同一冻结源码，不能称为已发布的版本化 OCI 镜像。

累计 40 次模型调用：T002 13 次（11 次正例尝试、2 次澄清）；T003 主旅程 3 次、补充视觉 1 次；RC.2、RC.3、RC.4、RC.6 固定 cohort 各 5 次；RC.4 CUA 另 2 次，RC.6 CUA 另 1 次；T004、RC.5 零次。RC.2 和 RC.3 各 3/4 正例及 2/2 负例，RC.4 和 RC.6 各 4/4 及 2/2，不拼接成首轮成功率。累计执行 37 次、未完成 0；这些累计数不等于成功数。

原模型、编译、窗口、视觉、驱动、smoke、性能及观察器失败均保留。A005 五个治理动作成功但原准备 wrapper 退出 1，A006 独立 GET-only 核验通过，不覆盖原失败；补充定义中的规范类别与别名不是确定性的值域解析器或完整映射治理。第五轮搜索 p95 340.855 ms 失败，第六轮修复后完整门禁为 22.854 ms，原 250 ms 门槛不变。

T003 补充视觉的 Playwright 子进程通过，原 launcher 退出 1 的原因未分类；独立后置核验通过不改写原命令失败。

RC.6 前端直接运行 40 文件 / 356 测试，lint 0 error、4 项既有 warning。Go 64 包（60 cached、4 实跑）、Node 116 项及启用的 uncached 性能继承 Round 7，不冒充 RC.6 重跑；正式 740 输入桥接仅包含约定构建范围，顶层 db/tests 不在其中。运行 SQLC 产物不变，性能定义与固定 HEAD 一致。标准浏览器、smoke、安全、包构建及验证在 RC.6 新鲜执行；完整源码由 PR CI 再验。源码中的 opt-in 性能跳过不记作通过。

## 限制与交付边界

升级证据限于含身份及工作区的 schema 32 至 33。恢复不覆盖外部业务源数据库、浏览器 cookie 或临时结果行，也不证明 RPO、RTO 或 SLA。修订未知结果的 pending key 仅保存在内存，刷新后需核对 operation；历史 producer 查找上限为 64 步。SQL 产物不支持内容预览。

取消不证明供应商立即停止或停止计费；同一主体已读的前端缓存可能在权限变更后仍保留内容，服务端操作重新授权。原 native 运行环境在第四轮前已停止，原因未知；没有重启或声称其持续可用。留给用户的是独立的健康 RC.6 候选环境。

私有配置曾经工具输出披露，凭据轮换未完成。生产使用前必须按批准流程轮换受影响凭据并保留密钥恢复能力；公开证据不包含凭据值。不得随意重置加密密钥。

代理验收与条件式 Git 交付已由用户明确授权，实际提交和合并结果以 PR 为准；不等同正式签名发布、镜像发布或远程部署。目录发布状态未完整加载时版本筛选禁用且显示待确认，已知完整结果可筛选。完整地址搜索及服务端内容/FTS 命中保持服务端成员边界，不以客户端摘要再次排除。
