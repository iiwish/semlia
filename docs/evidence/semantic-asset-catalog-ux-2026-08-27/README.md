# 语义资产目录交互验收

## 范围

- 产品表面：知识资产 / 资产目录
- 核心任务：搜索与筛选资产、比较目录结果、进入资产详情、返回目录
- 验收视口：默认桌面、1024 x 768 紧凑桌面

## 步骤与结论

1. **原目录与详情并列呈现：需要优化**
   - 目录和完整详情在紧凑桌面上纵向堆叠，选择后需要跨越较长页面理解上下文。
   - 目录列表被限制在较小滚动区，可比较行数少，筛选与结果之间的层级偏重。
   - 证据：[01-before.jpg](./01-before.jpg)

2. **全宽目录浏览：健康**
   - 搜索、类型、状态、语义域、清除和排序位于同一条命令区。
   - 结果按资产、类型与语义域、负责人、就绪度和状态排列，默认将需要关注的资产放在前面。
   - 目录不再同时渲染完整详情，列表具备稳定的扫描节奏。
   - 证据：[02-catalog-after.jpg](./02-catalog-after.jpg)

3. **独立资产详情：健康**
   - 选择目录行后进入独立详情工作面，六个局部视图使用完整内容宽度。
   - “返回资产目录”保留搜索、筛选、排序和浏览位置。
   - 证据：[03-detail-after.jpg](./03-detail-after.jpg)

4. **紧凑桌面目录与详情：健康**
   - 1024 x 768 下隐藏次要负责人列，保留资产、类型、就绪度、状态和进入详情的主要任务。
   - 页面、目录命令区、结果行、详情 Tab 均无水平溢出。
   - 证据：[04-catalog-1024.jpg](./04-catalog-1024.jpg)、[05-detail-1024.jpg](./05-detail-1024.jpg)

## 可访问性检查

- 搜索框、筛选、排序、清除、目录行、返回按钮和详情 Tab 均有可识别名称。
- 就绪度使用具名 `progress`，不只依赖颜色表达。
- 目录行与返回按钮支持键盘操作并保留可见焦点。
- 截图无法证明完整的读屏顺序、缩放体验和颜色对比合规，仍需在真实数据与辅助技术环境中复核。
