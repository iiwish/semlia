业务口径、对象属性与参数

SELECT 1.0 * SUM(o.paid_amount)
  / NULLIF(COUNT(DISTINCT o.order_id), 0)
  AS avg_order_value
FROM {{订单绑定表}} AS o
JOIN {{客户绑定表}} AS c
  ON o.customer_id = c.customer_id
WHERE {{有效订单条件}}
  AND o.paid_at >= :month_start
  AND o.paid_at < :month_end
  AND c.region = :region
  AND c.first_paid_at < :month_start;

手工编写的说明性 SQL，非原型输出。花括号为待核实绑定，冒号为参数；执行须验证与授权。

对话反馈：用户偏好与系统通用知识

用户对话选择、纠正与补充说明，按适用范围分别处理

用户偏好

仅当前用户，可修改、可删除

“以后先给结论，
再给表格。”

表达方式、详略与图表偏好

提取偏好 → 用户确认 → 个人生效

系统通用知识

发布后在授权业务范围内复用

“经营分析中的销售额，
不包含集团内部交易。”

形成销售额统计口径的修订候选

提取候选 → 验证审核 → 发布复用

个人偏好不改写业务口径；通用知识不因一次对话自动生效。

目标设计；仅本次有效的选择不默认长期保存，对话内容按授权与最小必要范围处理。
