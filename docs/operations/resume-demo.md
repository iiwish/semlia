## 展示内容

知识资产目录包含 5 个合成零售资产。变更与发布保留首次生产、退款口径纠正和版本回滚三条真实发布记录，以及可查看的纠正草稿。历史作者与审核者记录保留用于追溯，不需要使用这些账号登录。

## 启停

在仓库根目录执行：

```sh
node scripts/demo/cli.mjs up
node scripts/demo/cli.mjs status
node scripts/demo/cli.mjs verify
node scripts/demo/cli.mjs down
```

使用正常原生 server/worker，连接既有 OrbStack PostgreSQL 的专用演示数据库；不构建应用 Docker。停止和启动保留业务数据，既有开发实例不受影响。

`verify` 使用正常管理员会话，只读核对权限、资产、来源对账和发布历史。部署前验收结果见 `docs/evidence/DEMO-T001/predeploy-acceptance.md`。

旧验收账号的已知密码和会话已撤销；历史成员记录不删除。两个隐藏验收工作区保留不可登录的最后管理员记录，以遵守产品约束。多账号初始化、验收和批量密码重置命令不用于此单管理员交付环境。

`.semlia/resume-demo/retail-v1/` 包含数据库密码、内部密钥及会话文件，不应公开。登录密码只适用于本地演示；本说明不授权服务器部署。
