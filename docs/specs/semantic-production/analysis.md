## 非功能覆盖

- 安全：来源和操作恢复重新鉴权、跨工作区拒绝、职责分离、来源提示注入、最小数据与机器权限不扩张。
- 一致性：原子创建/发布、幂等、输入失效、并发、断网与进程/浏览器恢复，旧版本不变。
- 可复核性：固定来源与提案摘要、完整审核/发布关联、迁移与回滚、原始 AI 和人工修正分开。
- 桌面：1440x900、1024x768 的真实流程、键盘、焦点、reduced motion 和截图检查。
- 兼容与规模：旧单目标和四通道消费、生成物一致性、10,000 资产基准及既有 p95 门槛。

## 剩余风险

### 已处理：非空口径的可信业务规则确认

A002 的服务端确认记录绑定真实人类、版本、目标内容与证据摘要；缺确认、撤销、权限失效或版本变化阻断验证和发布。显式人类声明路径通过真实接口创建证据，不需要手工数据库预填。原反例、正向发布、并发原子性和职责分离均通过，详见 [修复复核](../../evidence/SP-T005/A002/review.md) 与 [验收复核](../../evidence/SP-T005/acceptance-review/re-review.md)。T005 为 Accepted。

### 历史数据库兼容检查

历史迁移测试使用精确起始版本及对应 schema 的夹具。T007 的五项定向检查和完整数据库 package 通过，包含 populated downgrade 拒绝、dirty marker 与历史值保留；正式迁移和 repository 未修改。修复授权、原失败及新鲜结果见 [数据库复核](../../evidence/SP-T007/A001/database-review.md)。

### 已处理：未决定义的确定性验证阻断

共享验证器独立阻断 null definition/scope，草稿 schema 仍接受未决内容。用户批准的修复包含失败 findings 持久化一致性及真实集成反例。全量治理与生成 race 检查通过，见 [修复记录](../../evidence/SP-T005/A001/validation-blocker.md) 和 [交付报告](../../evidence/SP-T005/summary.md)。

### High：生成运行及费用边界

T004 已验收，运行证据与残余边界见 [风险复核](../../evidence/SP-T004/A002/review.md)。T005 使用 migration 27 的生成请求/调用领取记录，成功输出继续使用既有不可变表。模型调用不处于数据库事务内，领取后的运行禁止自动重发供应商请求；无法确认的结果进入 outcome_unknown。服务端 grant 默认空，按主体、工作区、模型及配置修订限制；请求上限不能授予费用权限。保守计费上界仅用于执行门禁，实际费用未知时返回 null。产品边界保持不变，实施与反例验证由 A001 承担。

### Medium：单样本工期不能替代运行实现证据

位置：计划第 6、7、9 节与 SP-T002 至 SP-T007。T001 有真实计时、两轮 RED/GREEN、独立评审和基线证据；它只交付模型与接口契约，不证明数据库迁移、并发发布、恢复或新前端已可用。已有大量用户改动须持续保留，后续任务需重新核对工作区。

处理：逐项开放执行包，精确补齐 [后续文件归属](../../evidence/SP-T001/handoff.md)，SP-T002 记录实测并在 SP-T003 后再次校准；不得按 T001 缩短比例机械推算数据库/发布任务。用户验收、实际模型配置和额度等待不包含在有效小时内。

## 独立评审闭环

- 旧 rollback 路径：生产 release 及全部回滚后继继承保护，防止绕过集合权限和独立审核。
- Validation 重试：明确 attempt 身份、唯一约束迁移及完整结果选择，不混合不同尝试的通过结果。
- AI 输出恢复：不可变规范化原始输出与人工应用版本分别持久化，受限读取、授权和保留规则明确。
- 缺席身份再生产：使用 create 的受治理重引入，验证可信历史、当前缺席、身份唯一及 head CAS，不伪造 base。

四项修正均为契约级结论，真实事务、迁移、撤权/竞争及进程恢复断言由后续任务实现。详见 [首审](../../evidence/SP-T001/review-a001.md) 和 [复核](../../evidence/SP-T001/review-a002.md)。
