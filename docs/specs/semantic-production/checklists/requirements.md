## 需求质量

- [x] 四个用户故事都有主体、需要和可观察结果。[Completeness]
- [x] 首次生产从无语义资产、提案、release 和消费者的工作区开始，不靠预填业务对象通过。[Cold start]
- [x] 最小样例明确两个实体、一个口径、绑定、键、粒度、Join 与业务规则依据。[Scope]
- [x] 新建、更新、未发布草稿、已发布事实、AI 建议和人工批准相互区分。[Clarity]
- [x] 来源版本、成员、改名、删除、部分扫描和不可验证历史有明确要求。[Versioning]
- [x] 十项 FR 和五项 NFR 均映射验收场景与任务，全部十二项 AC 纳入最终验收。[Traceability]
- [x] 并发、重复、断网、清除缓存、权限撤销、输入注入和模型失败有拒绝或恢复行为。[Edge cases]
- [x] 验证、审核、发布与回滚使用同一输入版本，不能从单项入口绕过集合检查。[Consistency]
- [x] 实际模型与协议替身分别记录，无授权时不运行付费调用，也不虚报 AI 质量通过。[Evidence]
- [x] 桌面尺寸、无障碍、已有契约兼容与 10,000 资产性能门槛明确。[NFR]
- [x] 不扩展来源生态、消费场景、移动端、通用 AI 平台或自动发布等级。[Non-goals]
- [x] 七个任务串行且共享文件冲突明确；T001 已接受，用户授权继续 T002、T003，T003 需 T002 技术评审通过，没有并行 governed task。[Execution]
- [x] 数据模型和接口细节由 SP-T001 完成并审核后才开放后续实现，不隐藏高风险前置工作。[Gate]
- [x] 估算列出有效小时、缓冲、假设、置信度和重估检查点，不承诺日历完成时间。[Estimation]
