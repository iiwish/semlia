# 来源到问数的分阶段验收计划

状态：A 阶段的数据库结构浏览和 CSV/XLSX/Markdown 内容预览已获用户确认并进入交付；验证结果见 `source-preview-acceptance.md`。其他阶段为规划，不代表验收通过。
范围：第一方 Web 的来源接入、内容核对、知识生产、确认发布、问数及纠错。
依据：当前 SSOT、知识收敛契约、语义知识类型契约。外部 AI 接入专题仍后置，不启动另一套产品流程。

## 1. 目标与边界

用户能够看到接入了什么、判断材料是否正确、核对系统形成的知识，并用已发布知识得到可对账的数据结果。

验收单位是一个真实业务案例，而不是菜单、接口数量或页面是否能够打开。菜单结构保持稳定，内容浏览在现有来源详情中完成；不新增一级模块，不建设通用数据库管理工具、文档编辑器或任意 SQL 控制台。

每一阶段必须有可见结果、下一步动作和失败恢复方式。上一阶段未通过，不以后一阶段的演示或自动化通过代替。

## 2. 已核对的现状

2026-09-20 检查范围为当前本地来源详情、前端实现、公开 API 合同及发现适配器。没有执行新采集、查询业务明细、上传文件或调用模型。

| 能力 | 现状 | 规划含义 |
| --- | --- | --- |
| PostgreSQL 连接、发现与计划 | 已有连接、运行、计划和快照基础；当前详情主要显示状态与统计 | 优先让用户检查来源内容，不再只看到连接和运行成功 |
| 表字段结构 | 采集器读取表、视图、字段、类型、可空性及约束；有来源快照和成员分页接口 | 复用已有授权读取，补齐库/schema/表/字段的浏览与搜索；注释、覆盖范围等缺口单独核对 |
| 数据行预览 | 当前来源页及来源 API 合同中未发现用户可用的数据行预览入口 | 是受控业务数据读取能力，不是简单增加一个表格；已有执行适配器的安全机制可评估复用，不能直接绕过其语义执行契约 |
| 文件接入 | 当前普通文件上传限定 CSV、XLSX、Markdown；SQL/dbt 是另行处理的技术来源 | 文档与表格区分预览，不把 SQL/dbt 文件当作普通业务文档 |

| PDF/DOCX | 当前普通文件上传入口未声明支持 | 作为明确新增能力评估，不承诺仅打开浏览器预览即可生成知识 |
| 知识类型 | 生产接口接收七种类型枚举；AssetContent 主要是通用定义和范围字段 | 指标计算必须补齐可验证、可消费的结构化规则，不能只有文字说明 |
| 发布与问数 | 有治理与执行实现，不据此宣称真实业务闭环已完成 | 验收前重新检查真实来源、发布知识、执行连接、权限、预算和对账基准 |

## 3. 验收样本

先固定一个业务问题，再选择数据，而不是从全库自动生成知识后寻找用途。

- 一个获授权的数据库、2–3 张相关表、一份业务口径文档、一个指标。
- 三个可回答的问题：指标总量、按一个维度拆分、按时间比较。问题以实际字段和口径为准。
- 两个必须澄清或拒绝的问题：业务口径不明确、缺少授权或缺少已发布绑定。
- 一次纠错：修改明确的业务口径或来源字段，确认影响提示、修订、重验和结果变化。
- 由数据负责人准备同一数据快照或固定期间的基准 SQL；由业务负责人确认规则；按原权限安排独立审核和发布。

目标知识契约采用业务对象、业务口径、指标、数据资产和分析模型五类主要对象，属性与判定/计算规则保留强类型成员契约。样本包含含义易混淆的客户相关来源，验证“来源表 → 数据资产 → 业务知识”的引用；选定案例需覆盖数据集级及关键字段血缘。该目标不改变第 2 节注明日期的实现快照，也不表示数据资产类型已获实现验收。

测试先使用隔离、明确标记的合成数据覆盖失败情况；真实数据验收采用限定范围，不通过修改生产源表制造错误。验收材料不记录密码或完整敏感样本。

## 4. 阶段与通过条件

| 阶段 | 用户要完成的事情 | 必须交付的结果 | 通过条件 |
| --- | --- | --- | --- |
| A. 看清来源 | 确认数据库或文件确实是所需材料 | 数据库内容浏览、文件内容预览、范围与读取状态 | 能定位指定表/字段或文档段落；无权限、未读取和空内容不混为一谈 |
| B. 确定输入 | 只选择本案例相关材料参与生成 | 所选表/字段/文档及版本清单、明确覆盖范围 | 只处理所选范围；可取消和重试；重复运行不会形成难以区分的重复结果 |
| C. 核对知识 | 核对业务对象、字段含义和指标规则 | 结构化知识及逐项来源依据、明确待确认问题 | 每项关键定义、绑定、粒度、连接与计算规则有来源或人工决定；未知项不编造 |
| D. 确认发布 | 补充口径、检查、独立审核并发布 | 确定的已发布版本和可用性状态 | 阻断问题不能跳过；发布后待办退出，历史可追溯；失败不会显示成功 |
| E. 问数对账 | 提问、核对依据/SQL/数据结果 | 使用的知识版本、参数与来源、受控执行结果 | 三个问题与人工基准一致；金额精度、空值、时间边界和连接重复计数符合约定 |
| F. 变更恢复 | 发现错误并完成纠正 | 影响提示、修订知识、重验和可解释的新结果 | 旧引用仍可追溯；新查询不静默使用失效规则；恢复后不重复提交、不越权 |

“连接成功”“文件上传成功”“模型生成成功”“知识已发布”“查询成功”“结果正确”分别验收，不合并成一个成功标记。

## 5. 来源体验的具体范围

### 数据库内容

在现有来源详情内提供内容浏览，展示当前连接数据库及其 schema、表/视图；选择表后展示字段、类型、可空性、主键/外键及可取得的注释。字段注释与推测的业务含义必须区分。

- 当前连接绑定一个数据库。首轮在该数据库内浏览，不默认为账号可连接其他数据库，也不扩展为全实例数据库管理器。
- 明确区分已发现的元数据快照与实时样本，显示读取时间、版本、覆盖范围和失败状态。
- 搜索、分页、选择范围能覆盖大目录；部分授权或分页未完成时，不把已加载数量说成全库总数。
- 允许只选 2–3 张表继续知识生成，不强迫全库生成。首次读取和刷新范围也必须明确；尚未支持范围扫描时，清楚区分“采集范围”和“生成范围”，不能用前端筛选冒充后端限定。
- 结构变更提示哪些知识可能需要重新确认；不静默把新结构拼到旧版本证据中。

### 数据行预览

结构浏览权限不自动包含业务明细读取权限。预览需服务端逐对象授权、专用只读凭据和审计；不把开发环境宽松连接配置用于真实验收。

建议初始约束（待确认）：用户主动点击读取，默认 20 行，硬上限 100 行，5 秒超时，并限制响应字节数和单元格大小。表/字段来自授权目录，服务端构造限定查询；不开放任意 SQL，不默认执行全表 COUNT 或昂贵排序。视图及函数等执行面须评估可控性，未满足安全条件时明确不支持。

预览只用于识别材料，不代表全量质量或统计分布。敏感字段按明确策略隐藏或脱敏；无法确定可展示范围则拒绝。默认不持久化样本、不写入向量库、不发送给模型；模型使用样本必须另有明确授权和范围。

### 文档与表格内容

文件详情提供可读原文与解析结果，并能从知识引用跳回准确位置。显示文件版本、解析状态、支持范围及截断提示。

- Markdown：安全渲染正文、标题和段落，保留可定位引用；禁用可执行内容和自动外部资源加载。
- CSV/XLSX：按工作表、行列展示受限内容，明确编码、表头、空值、日期和公式值的处理方式，不执行宏或公式。
- PDF/DOCX：按真实业务材料需求单独确认优先级。验收必须同时覆盖正文提取、段落/页码定位及版本引用；扫描 PDF、OCR、加密文件和复杂表格不隐含包含在首轮范围内。
- 明确损坏、格式不支持、内容过大、部分解析和读取失败；失败不能成为“空文档”或“已成功接入”。
- 源文件更新形成新版本，旧知识引用保留对应旧版本；跨工作区和无权限账号不可预览。

## 6. 最小必测用例

| 编号 | 操作或条件 | 预期 |
| --- | --- | --- |
| S01 | 已授权数据库中找到指定表与字段 | 名称、类型、约束与原始来源一致，可查看采集版本 |
| S02 | 无权限表、空 schema、未执行发现、发现失败 | 四种状态可区分，不误报不存在或空数据 |
| S03 | 目录超过一页、切换表后旧请求晚返回 | 分页完整，旧响应不能覆盖新选择 |
| S04 | 授权样本预览、空表、敏感字段 | 有界读取，空表不报错，敏感内容按策略处理 |
| S05 | 样本超时、超限、权限撤销、取消 | 明确失败/限制，服务端也停止或受限，不泄露其他范围 |
| S06 | 支持格式文件打开、切换工作表/段落 | 内容与原件一致，解析结果可核对，引用能定位 |
| S07 | 错误格式、恶意内容、大文件、损坏文件 | 安全拒绝或明确部分支持，不执行脚本、宏或外部请求 |
| K01 | 选择材料并生成，再次生成或重试 | 来源版本和选定范围明确，重复操作可识别，无无依据事实 |
| K02 | 缺口径、实体键或连接粒度 | 提出具体待确认问题，不允许绕过发布条件 |
| K03 | 同名客户表、账号与客户不等价、历史快照多行 | 数据资产分别记录用途/粒度/时间；不以同名、中文名或标签自动合并或选表 |
| K04 | 保存数据资产、独立成员绑定与关联契约 | 无命名模型也能按原职责独立验证审核发布；API、存储与消费引用一致，缺加工实现时阻断 |
| K05 | 核对对象、属性、口径及指标的归属 | 不重复创建同名概念；属性稳定可寻址，定义与条件同版本，基础聚合和派生计算类型明确 |
| K06 | 成员变更与既有接口兼容 | 影响可追踪；旧 ID/release 可读，不按名称自动迁移；不能用现有通用字段冒充完整结构 |
| K07 | 重复提问或改变月份、地区、口径组合 | 生成临时计划，不增加模型数量；具有复用价值的候选去重后独立审核，不自动发布 |
| K08 | 新指标复用已确认关系；索引依赖变更 | 能力索引按指定 release 验证生成，公式不重复；过期索引失效，字段齐全不等于执行获准 |
| L01 | 关键字段或加工逻辑变化 | 沿数据血缘、实现映射、语义依赖定位待重验对象；未知区间、版本和授权范围可见 |
| L02 | 循环/过深关系、越权节点、推断血缘 | 有界查询与循环处理，不泄露未授权对象，不将推断或静态解析宣称为已验证运行事实 |
| G01 | 原作者自审、无权限发布、并发版本变化 | 保留职责分离、权限和版本冲突保护 |
| Q01 | 三个标准问题与两个负向问题 | 标准问题对账通过，歧义澄清或拒绝，越权拒绝 |
| Q02 | 同一问题分别有适用模型、无模型但获准依据完整 | 两条路径按同一数据快照对账；无模型计划的 modelRef 为空且不创建知识；若能力未就绪明确标为未通过 |
| Q03 | 无模型且缺少映射/关联，或仅有同名键 | 只生成候选/澄清，不执行未确认关联；单独授权验证不等于批准正式取数 |
| Q04 | 模型被政策限制、权限不足、实现有业务冲突 | 无模型回退不得绕过限制；多种非等价实现不按相似度直接选择 |
| Q05 | 组合关系产生扇出、超跳数/耗时，或执行前来源/权限变化 | 整条计划校验、预算限制与失效重验生效；单条关系已验证不自动放行多跳路径 |
| R01 | 文件/字段或指标口径变更后重验 | 可追溯影响，新旧版本不混用，纠错结果可解释 |
| F01 | 一段对话包含展示偏好、业务纠正及本次筛选意图 | 按陈述分流；本次选择不默认长期保存，不能把偏好直接当作通用口径 |
| F02 | 明确记忆或确认展示偏好，随后修改、删除或停用 | 仅当前工作区、当前用户生效；过期或撤回后不继续应用，跨用户读取被拒绝 |
| F03 | 本次展示要求与偏好冲突，或偏好要求绕过口径/权限 | 本次展示要求优先；业务定义、强制政策与权限不可被偏好覆盖 |
| F04 | 私有对话中的业务陈述拟进入通用知识 | 先检查共享授权和敏感信息；只形成有来源候选，验证、独立审核发布后限授权业务范围复用 |

## 7. 执行顺序和停止条件

1. 固定业务样本、文件格式、授权范围、只读凭据、模型预算、基准 SQL 与责任人。
2. 先完成 A 阶段的数据库结构浏览和现有文件格式的内容预览；所需原文格式缺失时先决定是否扩展解析，不以格式转换掩盖验收缺口。
3. 单独完成受控数据行预览，验证权限、超时、限量和脱敏；未就绪时明确标注不可预览，不阻塞纯元数据浏览。
4. 以同一个案例推进 B–D，补齐所选数据资产及指标必需的结构化信息、映射和关键血缘，按本案例完成五类知识及必要成员契约，不一次覆盖全部可选字段或全库自动解析。
5. 最后执行 E–F：真实问数对账和一次完整纠错。前序没有已发布且可执行的知识时，不声称已经闭环。

不在本轮默认范围：新增多种数据库连接器、全库明细浏览、全量知识自动发布、文档协同编辑、全格式 OCR、通用 SQL IDE、重新调整菜单架构。

## 8. 验收记录与发布门槛

每阶段记录用例、输入来源与版本、测试身份、期望与实际结果、截图/API 证据、问题严重度和复测结果。状态使用未开始、阻塞、失败、通过，不把“已实现”写成“已通过”。

- 功能层：关键真实接口和隔离数据集测试；正确性不能只靠截图。
- 界面层：1440x900 和 1024x768；键盘、返回/刷新、加载/空/错/部分成功及取消恢复。
- 数据层：来源匹配、引用准确、结构化规则可保存且可消费、同一数据基准上的结果对账。
- 安全层：工作区隔离、最小权限、敏感数据边界、读限额、模型预算及原有审核发布约束。
- 通过条件：无越权/泄露/错误发布/错误计算阻断项；每个必测用例有证据。可延期的展示问题必须明确列出，不能用总测试数量替代业务验收。

已确认的 A 阶段仅授权来源快照与现有支持格式的内容预览实现和验证。数据库业务明细读取、向模型提交材料和发布知识需单独确认。
