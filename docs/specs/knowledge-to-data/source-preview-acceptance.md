# A01 来源内容验收

日期：2026-09-20。范围：来源内容核对，不代表来源到 SQL 的闭环已经验收。

## 可用能力

- 数据来源详情的“内容”视图展示当前连接数据库、采集版本、覆盖状态、schema、表/视图和字段；支持表名/字段名搜索、目录分页、版本切换和刷新。每批自动读取最多 100 页，每页最多 200 个结构对象；仍有续页时显示继续加载与搜索覆盖限制。
- 字段类型、可空性和序号来自快照绑定的不可变版本，不查询当前业务数据库，不把当前结构填入历史版本。
- CSV/XLSX 支持工作表行列预览和解析结构；Markdown 支持惰性文本块、原文和解析结构。原文件集合弹窗也提供内容入口。
- 文件预览受 source.read 授权、工作区及集合成员关系约束；完整安全验证、内容摘要核对、解析后重新授权及保留状态检查。响应不缓存，不输出存储路径，不执行脚本、公式、宏或自动加载外部资源。
- 表格每工作表最多 100 条数据记录、50 列，单元格最多 1024 字节，总单元格文本预算 128 KiB。Markdown 原文最多 64 KiB，行/块投影分别最多 500 项。超限明确显示部分内容。

## 限制与待验收

- 独立浏览器的登录与合成文件上传脚本未通过登录步骤。未重置密码、未修改权限、未向当前工作区上传测试文件。该脚本不能算作通过证据；CSV/XLSX 的浏览器真实上传复测需有效的本地验收凭据。
- CSV/XLSX 的解析、服务组合、前端表格行为有自动化证据；真实页面本轮使用数据库快照和已有 Markdown 文件，不声称已在真实浏览器逐格式完成上传验收。
- 注释与主外键没有在现有结构投影保存，界面明确标示未记录；不推测或补造。包含多个点号的历史限定表名保留完整名称，不猜测 schema。
- 文件日期和数值显示存储值，不保证 Excel 格式化外观；无表头对应的数据列可能不展示并标明部分内容。Markdown 保留正文安全阅读，不提供文档编辑、外部链接跳转或完整 GFM 表格排版。
- 不含数据库业务行、PDF/DOCX、选择知识生成范围、模型调用、知识发布和 SQL 对账。
- 本地服务保持运行：`http://127.0.0.1:18081/sources`。入口为“数据接入 → 数据来源 → 打开来源 → 内容”。

## 复核结论

实现限定在只读来源核对边界，未增加菜单模块、迁移、后台采集或模型调用。原有工作区改动保留。用户手动验收及独立登录上传复测仍单独记录，不用自动化数量替代。
