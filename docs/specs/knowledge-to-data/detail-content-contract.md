# 知识详情信息契约

知识目录是桌面语义治理工作区，详情页优先回答业务问题，不作为数据库记录检查器。当前收敛范围为五类知识详情与发布详情，保持 API、权限、发布行为及数据不变。

| 类型 | 默认展示 |
| --- | --- |
| 业务对象 | 身份、粒度、生命周期、中文业务属性、值类型、空值和历史语义 |
| 业务口径 | 适用对象、判定条件、参数、求值阶段、空值处理 |
| 指标 | 聚合或派生计算、输入、固定口径、统计时间、单位、汇总规则 |
| 数据资产 | 用途与覆盖、粒度、字段及说明、更新、敏感级别、来源关联 |
| 分析模型 | 基础对象、场景粒度、公开属性、指标、口径、数据依赖与成员映射 |

名称、说明、状态在页头只展示一次。概览显示类型专属内容；定义页保留修订入口、有效边界和历史。空可选字段不渲染占位行。不可访问、读取失败、版本不一致与阻断信息不得为简洁而隐藏。

业务属性不显示物理字段引用。引用名称仅按匹配的修订解析，无法确认时显示“版本未加载”，不把当前名称冒充历史版本。来源关联未解析时明确状态，不用内部 ID 冒充表名。

发布详情只展示一份清单、发布状态与时间，以及确有数据的变更和消费影响。无名称的治理对象按真实类型区分，技术标识用于折叠追溯，不推测名称。回滚权限和确认流程保持不变。

内部 ID、schema 版本、摘要哈希、存储表名和原始载荷收纳到默认折叠的技术详情。删除重复说明、实现自述和重复计数；失败/未知不显示为成功或零。

视觉沿用现有中性画布与语义状态色；标题 16–24px，正文 13px，表格 12px，间距 12/16/24px。章节不加浮动卡片，重复对象可用独立小卡片；表格用行分隔。技术详情支持键盘展开和长标识换行。桌面验收尺寸为 1440×900 和 1024×768，不增加移动端范围。保留已有类型图标，不添加装饰图片或动画。

验证覆盖五类字段差异、版本引用不误配、空字段、错误状态、发布清单去重与分页、现有修订/回滚流程，运行类型检查、相关组件测试和桌面视觉检查。
