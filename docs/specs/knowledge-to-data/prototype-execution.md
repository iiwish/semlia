## K5-T01

目标：固定五类知识及结构化成员、引用、表达式的生产契约。允许路径、依赖和验证命令以实施计划 T01 为准。阅读输入为 `knowledge-types.md`、`data-assets-ontology-lineage.md`、`case-walkthrough.md`、项目 `AGENTS.md`。

接口：一级类型使用 business_object、business_term、metric、data_asset、analysis_model。草稿 spec 可为空；发布需要类型专属结构，引用不可变知识版本和来源快照。指标表达式使用封闭算子树，不能提交任意 SQL。

质量清单：旧类型拒绝；未知字段拒绝；成员 ID 唯一；引用固定版本；权限及发布验证不旁路；来源表只产生数据资产候选。先写失败测试，再实现，运行领域、应用、契约和数据库测试。发现授权缺口或不确定的数据删除范围时停止相关写入。

一致性分析：设计与计划类型一致。已知风险为现有生产引用解析会丢失版本、旧验证只检查定义/范围、目录把可读取误作通过；必须在行为测试中覆盖。不存在需要历史兼容的前置依赖。

证据保存于 `docs/evidence/knowledge-prototype-2026-09-21.md`，记录真实命令、测试结果、清理影响与未完成项。代码完成不等于用户验收。
