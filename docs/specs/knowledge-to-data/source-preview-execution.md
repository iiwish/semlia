# A01 来源内容核对

状态：实现、自动化与现有登录会话的桌面验收完成，等待用户手动验收。采用 Direct Execute，宿主未授权委派。证据见 `source-preview-acceptance.md`。

## 执行契约

目标：在现有来源详情核对已授权、版本化的数据库结构与 CSV/XLSX/Markdown 内容。菜单保持稳定，不执行数据库业务查询，不调用模型，不生成或发布知识。

允许修改：来源详情及独立内容组件、对应样式和测试；快照成员的只读投影；文件解析器、接入服务、HTTP 只读路由及对应测试；OpenAPI 和生成类型；本专题验收文档。保留工作区已有改动。无需数据库迁移。

依赖：现有 source.read 授权、不可变快照成员与字段版本、已完成接入的文件集合、内容摘要存储。文件预览必须验证集合成员关系、工作区、可用性、摘要及读取后的授权；不开放原始存储路径或任意文件读取。文件解析复用现有安全验证，响应有界，超限显示截断而不冒充完整文件。

内容设计：现有来源详情增加“内容”视图；数据库呈现固定连接库、采集版本、覆盖状态、schema/表搜索、字段类型和可空性。未保存的注释和约束明确标为未采集，不根据当前库或名称猜测历史值。文件显示集合版本、摘要、原文或工作表行列、解析结构和截断状态。旧请求不得覆盖新来源或新版本。

## 检查与验证

- TDD：先验证缺失的预览行为；覆盖 CSV、Markdown、XLSX 与安全拒绝、限量、历史字段投影、授权和成员边界。
- 后端：相关 Go 包测试、快照/接入隔离集成测试；合同生成及合同一致性检查。
- 前端：内容加载、分页、切换、错误、空内容、截断和无权限测试；全套 Vitest、类型、构建、lint。
- UI：1440x900 与 1024x768 检查内容定位、返回、键盘和横向滚动；本地服务保持可用。
- 完成条件：真实来源快照可核对，合成文件预览有自动化和浏览器证据，无跨工作区/成员泄露；准确列出未实现或未验证边界。用户手动验收独立于自动化完成。

## 一致性检查

本任务对应分阶段验收计划 A，不包含业务数据行预览、范围生成、PDF/DOCX、跨数据库实例浏览或 SQL 闭环。现有快照未保留 schema 的结构化名称，不能按点号盲拆含引号的 PostgreSQL 标识符；仅可按合法限定标识符解析，否则保留原名并显示未识别 schema。现有快照没有注释和完整约束投影，不能声称已展示这些数据。
