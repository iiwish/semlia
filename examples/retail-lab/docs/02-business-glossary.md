# 业务术语表

本表记录星禾零售日常沟通中的术语、别名和容易混淆的说法。分析问题时请先把口语映射到规范术语。

## 指标类术语

| 规范术语 | 常见说法 | 不要混淆为 | 备注 |
| --- | --- | --- | --- |
| GMV | 成交额、流水、销售流水、交易额 | 净销售额 | 运营周会常说“流水” |
| 净销售额 | 销售额、实收、净收入、营收、业绩 | GMV | 财务口径，口头“销售额”默认指它 |
| 支付订单数 | 单量、订单量、成交单数、订单数 | 下单数 | 下单数包含未支付订单 |
| 客单价 | 平均订单金额、笔单价、AOV | 人均消费 | 人均消费按会员数计算，本手册未定义 |
| 退款率 | 退货率、退款比例 | 退款单率 | 客服看板用退款单率 |
| 商品毛利 | 毛利、毛利额 | 利润、净利润 | 不含费用分摊 |
| 新客数 | 新客、首购会员、新会员首单 | 新注册会员数 | 按首单判断 |
| 复购率 | 回购率、回头客占比 | 留存率 | |
| 达成率 | 目标达成率、完成率 | | 只适用于门店及大区 |

## 业务对象

- **会员**：已注册的顾客，口语也叫“用户”“客户”。非会员订单的 `member_id` 为空。
- **回头客 / 老客**：注意区分。“回头客”在复购率语境下指统计期内买了 2 次及以上的会员；“老客”通常指统计期之前已经有过首单的会员。两者不同，提问时出现“老客”需要澄清。
- **门店**：线下门店，同时承担线上订单履约。“店”在加盟语境下指加盟门店。
- **员工内购**：员工会员下的订单，`order_type = staff`。
- **测试单**：系统联调产生的订单，`order_type = test`，任何指标都不得包含。

## 容易歧义的说法

- “销售额”：默认指净销售额；但运营同事口头说“销售额”有时指 GMV，涉及对外数据时需要确认。
- “8月的订单”：默认按支付时间归属到 8 月的有效支付订单，而不是 8 月下单的订单。
- “华南的业绩”：默认按门店当前归属大区统计。问 2026 年 7 月之前的华南业绩并要求“按当时归属”时，需要使用门店区域历史表。
- “库存”：月末快照，不能把多个月相加。
