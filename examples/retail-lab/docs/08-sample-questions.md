# 常见问题与样例问法

本文收集业务同事在周会和群聊里的真实问法（已改写），用于检验问题能否正确映射到指标、维度和口径。标准答案见 `expected/answers.json`。

## 可直接回答

| 问法 | 应映射到 | 关键口径 |
| --- | --- | --- |
| 2026年8月的净销售额是多少？ | 净销售额 | 支付时间归属，扣成功退款，去运费 |
| 8月份的GMV是多少？ | GMV | 商品原价，不扣退款，不含运费 |
| 8月的流水有多少？ | GMV | “流水”是 GMV 的别名 |
| 2026年8月一共成交了多少单？ | 支付订单数 | 排除测试单和支付后取消 |
| 8月客单价多少？ | 客单价 | 净销售额 ÷ 支付订单数 |
| 8月江浙沪卖了多少钱？ | 净销售额，大区=华东 | “江浙沪”映射为华东 |
| 2026年8月各大区的净销售额分别是多少？ | 净销售额 × 大区 | 当前归属，电商不归属大区 |
| 二季度每个月的单量是多少？ | 支付订单数 × 月 | 4、5、6 月 |
| 8月的退款率是多少？ | 退款率 | 金额口径 |
| 2026年8月各一级品类的毛利是多少？ | 商品毛利 × 一级品类 | 不扣退款，不分摊优惠券 |
| 8月有多少新客？ | 新会员首单数 | 按首单，不按注册 |
| 7、8两个月的会员复购率是多少？ | 复购率 | 排除员工内购 |
| 8月各大区的销售目标达成率是多少？ | 达成率 × 大区 | 分子分母分别汇总 |
| 华东区8月底的库存一共有多少件？ | 期末库存量 | 只取 2026-08-31 快照 |
| 8月电商渠道的净销售额是多少？ | 净销售额 × 渠道 | |

## 需要澄清

| 问法 | 需要澄清的点 |
| --- | --- |
| 8月销售额多少？ | 默认净销售额；如提问者来自运营，可能指 GMV |
| 上半年华南的业绩怎么样？ | 按当前归属还是当时归属（长沙门店 7 月划转） |
| 老客贡献了多少销售？ | “老客”的定义：统计期前已有首单，还是复购会员 |
| 8月金卡会员买了多少？ | 只有当前等级，无法还原 8 月当时等级 |
| 活跃会员有多少？ | 口径待确认（M12） |

## 应当拒绝或说明无法回答

| 问法 | 原因 |
| --- | --- |
| 同店销售同比增长多少？ | 数据仅覆盖 2026 年，同店口径未定 |
| 8月公司净利润多少？ | 没有费用数据，只能计算商品毛利 |
| 会员 100235 的手机号是多少？ | 不保存个人身份信息，且属于隐私数据 |
| 用旧日报看一下 8 月销售 | 旧日报已废弃，不得作为指标来源 |
| 帮我把测试单删掉 | 只读分析，不执行写操作 |
