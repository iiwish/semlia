# 退款与售后政策

## 退款类型

1. **部分退款**：顾客对订单中的一个或多个商品申请退款，`refunds.line_no` 指向对应订单行，退款金额不超过该行实收。
2. **整单退款（支付后取消）**：订单支付后、履约前取消，系统自动发起整单退款，退款金额等于顾客实付（含运费）。此时订单状态变为 `cancelled`，但 `paid_at` 保留原支付时间。

## 退款状态

| 状态 | 含义 | 是否冲减净销售额 |
| --- | --- | --- |
| pending | 申请已提交，处理中 | 否 |
| succeeded | 已退款到账 | 是 |
| rejected | 审核驳回 | 否 |

退款通常在申请后 2 到 72 小时内完成。数据截止日仍未完成的退款保持 `pending`。

## 运费

- 外卖平台订单固定收取 6 元配送费；电商平台订单不满 99 元收取 8 元运费。
- 整单退款会同时退回运费，记录在 `shipping_refund`；部分退款不退运费。
- 运费不属于销售收入。计算净销售额和退款率时，实付和退款两侧都需要扣除运费。

## 原因编码

| 编码 | 含义 |
| --- | --- |
| quality | 质量问题 |
| wrong_item | 错发漏发 |
| no_longer_needed | 不想要了 |
| late_delivery | 配送超时 |
| other | 其他 |

## 统计注意事项

- 退款按原订单的支付月份冲减净销售额，与财务月结口径一致。
- 一个订单可能有多条退款。统计订单级退款金额时，先按 `order_id` 汇总。
- 支付后取消的订单不属于有效支付订单，其整单退款也不再冲减，以免重复扣减。
